# ClaudeExchange

App desktop para alternar entre provedores AI (Claude, GLM, Minimax, Kimi) no Claude Code.

## Instalacao

### Windows

Corre no terminal (CMD ou PowerShell):

```powershell
powershell -c "irm https://raw.githubusercontent.com/stringao/claudeexchange-distro/master/install.ps1 | iex"
```

### Linux / macOS

```bash
curl -fsSL https://raw.githubusercontent.com/stringao/claudeexchange-distro/master/install.sh | bash
```

Depois reinicie o terminal e execute:

```
ClaudeExchange
```

## Instalacao manual

Descarregue o binario para a sua plataforma na [pagina de releases](https://github.com/stringao/claudeexchange-distro/releases/latest).

| Plataforma | Arquivo |
|------------|---------|
| Windows x64 | `ClaudeExchange-windows-x64.exe` |
| Windows x86 | `ClaudeExchange-windows-x86.exe` |
| Windows ARM64 | `ClaudeExchange-windows-arm64.exe` |
| Linux x64 | `ClaudeExchange-linux-x64` |
| macOS ARM64 | `ClaudeExchange-macos-arm64` |
